# Robowars 2026

A modern, highly dynamic Flutter application for VIT's flagship event **Robowars 2026**.

This repository contains the official mobile application for participants, providing real-time updates, leaderboards, profiles, and event schedules for the Robowars tournament.

---

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Before you begin, ensure you have the following installed on your machine:
- **Git**: For version control. [Install Git](https://git-scm.com/downloads)
- **Flutter SDK**: The framework used to build the app. [Install Flutter](https://docs.flutter.dev/get-started/install)
- **Android Studio** or **VS Code**: Recommended IDEs for Flutter development.

### 📥 Cloning the Repository

To clone the project to your local machine, run the following command in your terminal:

```bash
git clone https://github.com/your-organization/robowars_2026.git
cd robowars_2026
```

*(Note: Replace the URL above with the actual repository URL if it differs).*

### 📦 Installation

Once you have cloned the repository and navigated into the project folder, install all the required Flutter dependencies:

```bash
flutter pub get
```

### 🏃‍♂️ Running the App

To run the app, ensure you have a physical device connected (with USB Debugging enabled) or an emulator running. 

Then, execute:

```bash
flutter run
```

## 🌟 Key Features

- **Participant Profiles**: View your stats and team details.
- **Leaderboards**: Track the current standings of the tournament in real-time.
- **Dynamic UI**: Features a beautiful, highly aesthetic user interface complete with interactive elements and a custom audio visualizer.
- **Cross-Platform**: Built with Flutter to run seamlessly on both Android and iOS devices.
